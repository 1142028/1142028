# 詹正宇 Jam

元智大學學生。從寫小遊戲開始接觸程式，現在的目標是把「寫得出來」練到「寫得好、可讀、可擴充」。

這裡的作品大多保留了當時的寫法和舊版本，每個 repo 的 README 最後都有一段「現在回頭看」，記錄我現在會怎麼改。

## 作品時間軸

| 時間 | 作品 | 技術 | 重點 |
|---|---|---|---|
| 2023 秋 | [car-game-pygame](https://github.com/1142028/car-game-pygame) | Python / Pygame | 第一個遊戲，高二多元選修與楊鈞翔共同協作：季節、日夜切換與動畫 |
| 2024-01 → 2025-11 | [zombie-shooter-pygame](https://github.com/1142028/zombie-shooter-pygame) | Python / Pygame | 做完賽車遊戲覺得程式難維護，改練模組化 OOP，commit 歷史保留每一版 |
| 2025-03 → 04 | [stock-radar](https://github.com/1142028/stock-radar) | Python / requests / Tkinter | 爬股價 → 判斷 → 通知，從 LINE Notify 改成 Email |
